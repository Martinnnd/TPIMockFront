# Equipo 2000s

Esta carpeta pertenece a la pareja de esta epoca.

- Persona A: `theme.ts` y `theme.css` (identidad visual, responsive y accesibilidad).
- Persona B: `Chrome.tsx` y `Player.tsx` (estructura visual; usar los callbacks del contrato).
- En conjunto: `content.ts` y `contract.test.ts`.

No importar otra epoca ni los agregadores. Mantener IDs de contenido y nombres de props.

Pruebas: `npm run test:era -- 2000s` y `npm run check`.

Ver la [guia de trabajo](../../../docs/TRABAJO_EN_EQUIPO.md) para contratos, alcance del motor y revisiones.
