# Equipo 2010s

Estética de red social de 2011–2013. Cada archivo pertenece a este equipo:

- `theme.ts` y `theme.css`: textos, colores y estilos exclusivos `.era-2010`.
- `Chrome.tsx`: marco de la página.
- `ProfileIdentity.tsx`: portada e identidad del perfil.
- `Player.tsx`: iPhone 4; los controles y Spotify se reutilizan desde `PlayerFrame`.
- `content.ts`: siete relatos ficticios, tres datos documentados y dos canciones.
- `index.ts`: contrato del módulo.

Una persona puede trabajar en interfaz/perfil y otra en reproductor/contenido. No importar otras épocas. Ejecutar `npm run check` y `npm test` antes de integrar.

Las fuentes de Apple, NASA y Disney están enlazadas en cada dato. El año de Rolling in the Deep corresponde al álbum 21 de 2011. El teléfono es una ilustración CSS y los controles de reproducción pertenecen a Spotify; no representa la reproducción automática.
